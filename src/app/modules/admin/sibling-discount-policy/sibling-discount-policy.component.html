Sibling Discount Policy

When enabled, the auto-discount is applied at fee-invoice creation for students sharing a Family Code. The first enrolled sibling pays full fees; later children get the configured % discount. Cashier-supplied discount overrides this automatic value.

Rank is decided by ascending Enrollment Date among enrolled siblings sharing a Family Code (set on the student form).

Suggested BD pattern: 10 % / 15 % / 20 %. Set all values to 0 to log siblings without applying a discount.
